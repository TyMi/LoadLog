# data/

Hier liegen lokale LabRadar-Exporte. Der Inhalt dieses Ordners wird **nicht**
versioniert (siehe `.gitignore`), mit Ausnahme von `data/examples/`.

In `data/examples/` dürfen nur **synthetische oder vollständig anonymisierte**
Beispieldaten liegen (keine Namen, Orte, Waffen- oder Geräte-Seriennummern (z. B. `LBR-…`), Zeitstempel
mit Personenbezug).
